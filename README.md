# hermes-slim.com

Static download page for [hermes-slim](https://github.com/talos-hq/hermes-slim), served by GitHub Pages at https://hermes-slim.com.

- `index.html`, `style.css`, `app.js` — no build step.
- Icon assets in `assets/` come from the 1254×1254 source artwork.

Preview locally: `python -m http.server -d . 8000`.
