Terminal

Why slim

One file, already built

CPython, Hermes and every dependency come prebuilt in one archive. Your machine never compiles anything or downloads packages one by one.

Antivirus-friendly

No chain of package managers pulling dozens of files at install time, the pattern security tools flag.

Fast and resumable

The download uses 8 parallel connections and picks up where it stopped. Unpacking on Windows takes seconds, not minutes.

Ready on first launch

Setup asks a few questions, wires up the model provider and starts the gateway as a service, so Hermes is running when setup ends.
